# Atlas Voice Concierge

This project shows how to wrap the ElevenLabs Convai web component inside a
rebranded experience built with Next.js and TypeScript. The widget is lazy
loaded on the client, exposes custom branding attributes, and hides the default
"powered by" text so you can present the agent as your own.

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) to interact with the
rebranded widget.
